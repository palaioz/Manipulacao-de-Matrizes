# Manipulação de Matrizes

Produto de Aprendizagem II - Algoritmos e Programação B | Ciência da Computação - UFN

Sistema em linguagem C para manipulação dinâmica de matrizes NxN utilizando ponteiros, funções e alocação de memória.

## Funcionalidades do Sistema
- Entrada manual de elementos pelo usuário ou geração randômica
- Verificação de matriz simétrica, diagonal, triangular superior e triangular inferior.
- Multiplicação por escalar, soma da diagonal principal e vetor com a soma de cada linha.

## Como compilar e executar
Certifique-se de ter um compilador C (como o GCC) instalado. No terminal, execute:

```bash
# Compilar o programa
gcc main.c -o programa

# Executar
./programa
```
